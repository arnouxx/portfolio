## Reporting a Vulnerability

Security of this project and its visitors is taken seriously. If you discover a security vulnerability, please report it responsibly:

1. **Email**: Send details of the vulnerability to [abdulazim49787@gmail.com](mailto:abdulazim49787@gmail.com) with the subject `Security Vulnerability Report - Portfolio`.
2. **Details**: Please include:
   - A description of the issue and potential impact
   - Steps to reproduce or proof-of-concept
   - Any suggested mitigations
3. **Response Time**: You will receive an acknowledgment within 48 hours.

Please do not open public GitHub issues for security vulnerabilities until they have been addressed.
